100x Fitness — design system specimen

A non-clinical fitness and recovery app (Flutter, Android first). The home screen uses glanceable hero tiles, the rest uses calm light cards, and there is one guardrailed AI voice. Every colour carries a label. A missing value is never shown as zero. The values on this page are illustrative, not real member data.
